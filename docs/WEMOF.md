# WEMOF (Wakkyai's Entry Model Of FX) - ウェモフ

## 概要

WEMOF（ウェモフ）は、お笑い芸人兼FXトレーダーの**わっきゃい**氏が開発した、ボリンジャーバンド±3σでの**逆張りスキャルピング手法**。
名前の由来は「**W**akkyai's **E**ntry **M**odel **O**f **F**X」。

> "トレンドトレードは期待、逆張りトレードは結果" — トレーダーJun著書より引用

## 基本思想

- 価格が±3σに到達した際、**説明不能な値動き**（ニュースや重要レベルのブレイクでない）であれば、2-3pipsの平均回帰がほぼ確実に発生する
- わっきゃい氏はこれを「気持ち悪い値動き」「チャートの音色が違う」と表現
- ボリンジャーバンドの7本線を「7本の弦」に例え、弦が異常に振動する瞬間を捉える

## インジケーター構成

### 1. ボリンジャーバンド 7本線

| バンド | 色 | 説明 |
|--------|-----|------|
| +3σ | 濃い青 (#3f51b5) | エントリートリガー（ショート） |
| +2σ | 中間青 (#7986cb) | 警戒ゾーン |
| +1σ | 薄紫 (#b39ddb) | 通常範囲 |
| SMA(20) | グレー (#9e9e9e) | 中央線 |
| -1σ | 薄紫 (#b39ddb) | 通常範囲 |
| -2σ | 中間青 (#7986cb) | 警戒ゾーン |
| -3σ | 濃い青 (#3f51b5) | エントリートリガー（ロング） |

- **期間**: 20（標準設定）
- **時間足**: 5分足推奨

### 2. %B（パーセントB）- 3σ基準

通常のBB %Bは±2σ基準だが、WEMOFでは**±3σ基準**で計算する。

```
%B = (価格 - lower_3σ) / (upper_3σ - lower_3σ)
```

| %B値 | 位置 |
|------|------|
| 1.0 | +3σ |
| 0.833 | +2σ |
| 0.667 | +1σ |
| 0.5 | SMA中央線 |
| 0.333 | -1σ |
| 0.167 | -2σ |
| 0.0 | -3σ |

- %B ≥ 1.0 → 価格が+3σ以上（ショート候補）
- %B ≤ 0.0 → 価格が-3σ以下（ロング候補）

### 3. Delta %B（%B変化率）

%Bの1バー前との差分。異常な値動きの定量的検出に使用。

- ヒストグラム表示（緑=上昇、赤=下降）
- 直近20期間の標準偏差の2倍を超える、または固定閾値0.15を超える場合に「異常」と判定

## エントリーロジック

### ステップ1: トリガー検出
価格が**±3σにタッチ**（%B ≤ 0 or %B ≥ 1）

### ステップ2: 異常検出
Delta %B（%Bの変化率）が以下のいずれかを満たす:
- 直近20期間のDelta %B標準偏差の**2倍**を超える
- 固定閾値 **0.15** を超える

### ステップ3: フィルター（スキップ条件）

以下に該当する場合は「説明可能な動き」としてエントリーを**見送る**:

| フィルター | 説明 |
|-----------|------|
| **連続足フィルター** | 同方向のローソク足が5本以上連続 → トレンドブレイクの可能性 |
| **ピボットフィルター** | 価格がS2/S3/R2/R3付近（±0.1%以内）→ テクニカル的に説明可能 |

> **注意**: わっきゃい氏のオリジナル手法には、ニュースや経済指標による主観的フィルターも含まれる。
> これは完全な自動化が困難なため、本実装ではチャート上のマーカーとして表示し、最終判断はトレーダーに委ねる。

### ステップ4: シグナル生成

- **W↑ (緑矢印)**: -3σタッチ + 異常検出 + フィルター通過 → **ロング**
- **W↓ (赤矢印)**: +3σタッチ + 異常検出 + フィルター通過 → **ショート**

## トレード管理

| パラメータ | 値 | 備考 |
|-----------|-----|------|
| **利確** | 2-3 pips | 極めてタイト |
| **損切り** | 50-100 pips | 非常にワイド（稀にしか発動しない） |
| **日次目標** | 10 pips | わっきゃい氏は10pips/日で十分としている |
| **ホールド時間** | 数秒〜数時間 | 平均回帰が発生するまで |
| **取引通貨** | USD/JPY（主力）、XAU/USD | |
| **時間足** | 5分足 | |

## パラメータ一覧

| パラメータ | デフォルト | 範囲 | 説明 |
|-----------|-----------|------|------|
| `bb_period` | 20 | 5-50 | ボリンジャーバンド期間 |
| `pctb_delta_threshold` | 0.15 | 0.05-0.50 | %B変化率の異常判定閾値 |
| `consecutive_filter` | 5 | 3-10 | 連続同方向足のスキップ閾値 |

## 本実装での表示

### チャートインジケーター
「WEMOF (ウェモフ)」を選択すると以下が表示される:

1. **BB 7本線** (-3σ〜+3σ) がチャート上にオーバーレイ
2. **%B ライン** (マゼンタ) がサブパネルに表示
   - 1.0ライン (+3σ) と 0.0ライン (-3σ) の水平線付き
3. **Delta %B ヒストグラム** がサブパネルに表示
   - 緑=上昇、赤=下降
4. **エントリーシグナル** (W↑/W↓ マーカー) がチャート上に表示

### バックテスト
「WEMOF(ウェモフ)」戦略としてバックテスト可能。
平均回帰（ミーンリバージョン）戦略として分類される。

## 注意事項

- WEMOFは**エントリー手法**であり、完全な取引システムではない
- わっきゃい氏の手法の核心は「説明不能な動き」の**主観的判断**にある
- 本実装は定量的に再現可能な部分を自動化し、主観的判断はトレーダーに委ねるアプローチ
- ナンピン（追加ロット投入）はリスク管理上推奨されないため、本実装には含まない
- 公式のWEMOFインジケーターは松井証券のキャンペーンでTradingView用に配布されている（非公開ソース）
