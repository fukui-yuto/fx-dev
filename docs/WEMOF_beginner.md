# WEMOF（ウェモフ）をゼロからわかりやすく解説

## WEMOFって何？

WEMOF（ウェモフ）は、お笑い芸人の**わっきゃい**さんが考えた FX のトレード手法です。
名前は「**W**akkyai's **E**ntry **M**odel **O**f **F**X」の略。

一言でいうと：

> **「価格が異常に動きすぎたとき、ちょっとだけ戻るのを狙う」**

これだけです。

---

## たとえ話で理解する

### ゴムひものイメージ

価格の動きを**ゴムひも**だと思ってください。

```
        ぐいーーーっ！（伸びすぎ）
       /
      /
─────●───────────── 普通の位置（平均）
      \
       \
        びよーーーん！（戻る）← ここで2-3pips取る
```

- ゴムは伸ばしすぎると、必ず少しは戻る
- WEMOFは「伸びきった瞬間」に「ちょっと戻る分だけ」を取る手法
- 大きく戻るのを待たない。**たった2〜3pips**だけもらう

### でも注意！

ゴムが伸びる理由が**ニュースや重要イベント**のときは、ゴムが切れる（戻らない）ことがある。
だからWEMOFでは「**なぜ伸びたのか？**」を必ず確認します。

---

## 使うツール（インジケーター）

WEMOFで使うのは主に3つだけ。

### 1. ボリンジャーバンド（7本の線）

チャートに表示される**7本の線**です。

```
  ── +3σ ──  ←  ここまで来たら「伸びすぎ」（ショート候補）
  ── +2σ ──     警戒ゾーン
  ── +1σ ──     普通
  ── SMA  ──    平均（真ん中）
  ── -1σ ──     普通
  ── -2σ ──     警戒ゾーン
  ── -3σ ──  ←  ここまで来たら「伸びすぎ」（ロング候補）
```

- σ（シグマ）= 統計学の「標準偏差」
- ±1σの中に価格がある確率: 約68%
- ±2σの中にある確率: 約95%
- **±3σの中にある確率: 約99.7%**

つまり、**±3σの外に出ることは0.3%しかない**超レアな状態。
WEMOFはこの「超レアな瞬間」だけを狙います。

### 2. %B（パーセントB）

「今の価格がボリンジャーバンドのどの位置にいるか」を数字で表したもの。

```
  %B = 1.0  → 価格が +3σ の位置（上限ギリギリ）
  %B = 0.5  → 価格が真ん中（SMA）
  %B = 0.0  → 価格が -3σ の位置（下限ギリギリ）
```

- %B が **1.0以上** → 上に飛び出した！ → ショート候補
- %B が **0.0以下** → 下に飛び出した！ → ロング候補

### 3. Delta %B（%Bの変化スピード）

%Bが「どれくらい急に動いたか」を表します。

- 普段は小さくゆらゆら → 正常
- **突然大きくビクッと動く** → 異常な値動き！ → チャンス

---

## WEMOFのエントリー手順

### ステップ1: 価格が±3σにタッチしたか確認

```
%B ≥ 1.0（+3σ超え）→ ショート（売り）の準備
%B ≤ 0.0（-3σ割れ）→ ロング（買い）の準備
```

### ステップ2: 「異常な動き」かチェック

Delta %Bが普段より大きい？
- YES → 次のステップへ
- NO → 見送り（普通の値動きなだけ）

### ステップ3: 「説明できる動き」なら見送る

以下の場合は、伸びた理由がはっきりしているのでスキップ：

| こんなときはスキップ | 理由 |
|---|---|
| ニュースが出た直後 | ニュースで動いた → まだ伸びる可能性 |
| 重要な価格帯（150.000円など）を突破した | ブレイクアウト → 勢いが続く可能性 |
| 同じ方向のローソク足が5本以上続いている | 強いトレンド → 逆らうと危険 |
| ピボットのS2/R2付近 | テクニカル的な節目 → 予想通りの動き |

### ステップ4: エントリー！

「理由がわからないのに異常に動いた」→ これがチャンス！

```
-3σを割った → ロング（買い）→ 2-3pips上がったら利確
+3σを超えた → ショート（売り）→ 2-3pips下がったら利確
```

---

## 利確と損切り

| | 値 | 説明 |
|---|---|---|
| **利確** | 2〜3 pips | とても小さい。欲張らない |
| **損切り** | 50〜100 pips | とても大きい。めったに発動しない |
| **1日の目標** | 10 pips | わっきゃいさんは「10pipsで十分」と言っている |

### なぜ利確がこんなに小さいの？

- ±3σまで飛んだ価格は、**ほぼ確実に2〜3pipsは戻る**
- 大きく取ろうとすると逆行のリスクが増える
- 「確実に取れる分だけもらう」がWEMOFの哲学

### なぜ損切りがこんなに大きいの？

- 3σタッチのフィルターを厳しくしているので、そもそも負けにくい
- わっきゃいさんは**20〜30連勝が普通**と言っている
- 損切りは「万が一のための保険」という位置づけ

---

## わっきゃいさんの名言

> 「トレンドトレードは**期待**、逆張りトレードは**結果**」

- トレンドに乗る = 「これから伸びるだろう」という期待で入る
- WEMOFの逆張り = 「すでに異常に伸びた」という結果を見て入る
- 結果を見てから入るほうが確実性が高い、という考え方

---

## WEMOFが向いている人

- コツコツ小さく稼ぐのが好き
- チャートを見ていられる時間がある（5分足スキャルピング）
- 「待つ」のが苦にならない（シグナルは頻繁には出ない）
- USD/JPY か XAU/USD を主にトレードする

## WEMOFが向いていない人

- 一度に大きく稼ぎたい
- チャートを見続ける時間がない
- ニュースや経済指標のチェックが面倒
- 感覚的な判断が苦手（WEMOFには「チャートの雰囲気を読む」部分がある）

---

## 本ツールでの使い方

### チャートで見る

1. チャート画面のインジケーター選択で **「WEMOF (ウェモフ)」** を選ぶ
2. 自動的に以下が表示される：
   - チャート上: **ボリンジャーバンド7本線**（-3σ〜+3σ）
   - サブパネル: **%B ライン**（マゼンタの線）と **Delta %B**（緑/赤の棒グラフ）
   - シグナル: **W↑**（緑矢印 = 買い）/ **W↓**（赤矢印 = 売り）

### バックテストで検証する

1. バックテスト画面で戦略 **「WEMOF(ウェモフ)」** を選ぶ
2. 過去のデータでどれくらい勝てたか確認できる

---

## 注意

- WEMOFは「エントリーのタイミング」を教えてくれる手法であり、**完全自動売買ではない**
- わっきゃいさんの手法の核心は「チャートの雰囲気」を読む**感覚的な判断**にある
- 本ツールはその感覚を数値化（%Bの変化率など）して補助しているが、最終判断はトレーダー自身が行う
- **デモ口座で十分に練習してから実運用すること**
